## API Reference
- [General](https://docs.zushealth.com/reference/general.md)
- [Create an app client](https://docs.zushealth.com/reference/create-app-client.md): Creates a client for applications to make calls to the Auth Service API.
- [List all app clients](https://docs.zushealth.com/reference/get-app-clients.md): Lists all app clients.
- [Rotate app client secret](https://docs.zushealth.com/reference/rotate-app-client-secret-1.md): Rotates (ie. changes) the app client secret.
- [Updates an app client](https://docs.zushealth.com/reference/update-app-client.md): Updates an app client, updating all fields. Any fields omitted in the request body will be blanked in the existing app client object.
- [Modifies an app client](https://docs.zushealth.com/reference/modify-app-client-1.md): Partially updates a app client, only updating fields specified in the request body. Any fields omitted in the request body will not be changed from their existing values.
- [Get an app client by ID](https://docs.zushealth.com/reference/get-app-client-by-id.md): Get an app client by ID.
- [Delete an app client by ID](https://docs.zushealth.com/reference/delete-app-client.md): Delete an app client by ID.
- [Get an app client's settings by ID](https://docs.zushealth.com/reference/get-app-client-settings-by-id-1.md): Get an app client's settings by ID.
- [Modifies an app client's settings by ID](https://docs.zushealth.com/reference/modify-app-client-settings-1.md): Partially updates app client settings, only updating fields specified in the request body. Any fields omitted in the request body will not be changed from their existing values.
- [List all roles](https://docs.zushealth.com/reference/get-roles.md): Lists all managed roles and roles owned by the user's builder.
- [Get role details](https://docs.zushealth.com/reference/get-role-by-id.md): Get details about a single role by ID.
- [Create a user](https://docs.zushealth.com/reference/create-user.md): Creates a user.
- [List all users](https://docs.zushealth.com/reference/get-users.md): Lists all users.
- [Updates a user](https://docs.zushealth.com/reference/update-user.md): Updates a user, updating all fields. Any fields omitted in the request body will be blanked in the existing user object.
- [Modifies a user](https://docs.zushealth.com/reference/modify-user-1.md): Partially updates a user, only updating fields specified in the request body. Any fields omitted in the request body will not be changed from their existing values.
- [Get a user by ID](https://docs.zushealth.com/reference/get-user-by-id.md): Get a user by ID.
- [Delete a user by ID](https://docs.zushealth.com/reference/delete-user.md): Delete a user by ID.
- [Get the calling user](https://docs.zushealth.com/reference/get-calling-user.md): Get the calling user.
- [Token Exchange](https://docs.zushealth.com/reference/exchange-token-1.md): Exchanges an OIDC-compliant ID token from a user's identity provider for a Zus access token that can be used to make API calls
- [Token Proxy](https://docs.zushealth.com/reference/proxy-token.md): Allows an authorized user or app client to retrieve an access token for a user their builder can access. This feature requires additional permissions. Please [contact Zus](https://docs.zushealth.com/page/contact-support) if interested.
- [Start a job to retrieve information about the patient](https://docs.zushealth.com/reference/post_patient-history-jobs.md): This endpoint takes a reference for a patient that is stored in the FHIR server and starts a job that will asynchronously collect, parse and store on the server all documents that are related to this patient that are available on the external sources.
- [Get patient history job list](https://docs.zushealth.com/reference/get_patient-history-jobs.md): This endpoint retrieves patient history jobs info filtered by provided parameters and ordered descending by created date.
- [Check the status of a job](https://docs.zushealth.com/reference/get_patient-history-jobs-job-id.md): This endpoint returns information about the given job, including current status.
- [Delete a scheduled job](https://docs.zushealth.com/reference/delete_patient-history-jobs-job-id.md): This endpoint deletes a scheduled patient history job.
- [EnrollmentStatuses](https://docs.zushealth.com/reference/enrollmentstatuses.md)
- [List enrollment statuses](https://docs.zushealth.com/reference/get_enrollment-statuses.md): The enrollment status is a linkage between a ZAP subscription package and a patient. If a status object does not exist for a patient/package combination, which indicates that the patient is not enrolled in that package.
- [Create a new enrollment](https://docs.zushealth.com/reference/post_enrollment-statuses.md): Enroll a patient in a package.
- [Retrieve a specific package enrollment status](https://docs.zushealth.com/reference/get_enrollment-statuses-patientid-packageid.md): This endpoint can be used to retrieve a specific package enrollment status using the enrollment status id. Enrollment status id is a combination of the patient ID and the package ID in the following format "patientId:packageId"
- [Delete an existing enrollment](https://docs.zushealth.com/reference/delete_enrollment-statuses-patientid-packageid.md): This endpoint can be used to hard delete a specific package enrollment status using the enrollment status id. Enrollment status id is a combination of the patient ID and the package ID in the following format "patientId:packageId"
- [Update an existing enrollment](https://docs.zushealth.com/reference/patch_enrollment-statuses-patientid-packageid.md): This endpoint can be used to update a specific package enrollment using the enrollment status id. Enrollment status id is a combination of the patient ID and the package ID in the following format "patientId:packageId"
- [List all available packages](https://docs.zushealth.com/reference/get_packages.md): A "package" defines the breadth and refresh frequency of clinical data within a patient's Zus Aggregate Profile (ZAP).
- [Retrieve details for a specific package.](https://docs.zushealth.com/reference/get_packages-packageid.md)
- [Upload a document to be ingested into Zus as FHIR resources.](https://docs.zushealth.com/reference/post_upload.md): Use this endpoint to upload clinical documents to be transformed into FHIR resources and stored in Zus. Accepts PDF and CCDA formats.
